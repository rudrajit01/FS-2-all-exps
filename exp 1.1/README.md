# 4-in-1 Create Post

A modern React.js application that allows users to create and preview posts for multiple social media platforms from a single interface.

## 🚀 Features

- 📝 Create posts in one place
- 📱 Live post preview
- 🎨 Clean and responsive user interface
- ⚡ Fast and lightweight React application
- 🔄 Easy to customize and extend

## 🛠️ Built With

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/rudrajit01/4-in-1-create-post.git
```

Go to the project folder:

```bash
cd 4-in-1-create-post
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will run at:

```
http://localhost:3000
```
